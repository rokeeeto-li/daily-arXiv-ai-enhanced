*Gyujin Sim,Seungjoo Shin,Hosung Jeon,Gwangsoon Lee,Hyon-Gon Choo,Sunghyun Cho*

Main category: cs.GR

TL;DR: CoherentRaster is a 3DGS-based light field rendering framework that performs subpixel-level rasterization using Cross-view Coherent Attribute Reuse and View-coherent Remapping to enable real-time, high-quality light field synthesis on consumer-grade hardware.


<details>
  <summary>Details</summary>
Motivation: Light field displays require rendering interlaced images encoding many view-dependent observations, creating substantial computational overhead that makes real-time rendering difficult. While 3D Gaussian Splatting (3DGS) is efficient for single-view rendering, directly extending it to LFDs is computationally expensive. Prior accelerations either suffer from GPU inefficiency under spatially incoherent subpixel layouts or rely on computationally heavy multi-plane intermediates.

Method: CoherentRaster employs two key techniques: (1) Cross-view Coherent Attribute Reuse to eliminate redundant computation across neighboring viewpoints, and (2) View-coherent Remapping to restore warp-level memory efficiency degraded by the interlaced subpixel layout. The method performs subpixel-level rasterization to optimize both computation and memory access patterns.

Result: CoherentRaster provides an efficient pipeline for real-time, high-quality light field synthesis on consumer-grade hardware, addressing both computational overhead and memory efficiency challenges.

Conclusion: The method successfully bridges the gap between 3DGS's single-view efficiency and LFDs' multi-view requirements by optimizing both computational redundancy and memory access patterns, making real-time light field rendering achievable on standard hardware.

Abstract: Light field displays (LFDs) require rendering an interlaced image that encodes many view-dependent observations. This multi-view requirement introduces substantial computational overhead, making real-time rendering difficult to achieve. While 3D Gaussian Splatting (3DGS) is efficient for single-view rendering on 2D displays, directly extending it to LFDs is computationally expensive. Moreover, prior accelerations either suffer from GPU inefficiency under spatially incoherent subpixel layouts or rely on computationally heavy multi-plane intermediates. In this paper, we propose CoherentRaster, a 3DGS-based light field rendering framework that performs subpixel-level rasterization. Our method employs Cross-view Coherent Attribute Reuse to eliminate redundant computation across neighboring viewpoints and applies View-coherent Remapping to restore warp-level memory efficiency degraded by the interlaced subpixel layout. Together, CoherentRaster provides an efficient pipeline for real-time, high-quality light field synthesis on consumer-grade hardware.

### [32] [AGIPC: Adaptive In-Solve Algebraic Coarsening for GPU IPC](https://arxiv.org/abs/2605.04773)
*Xuan Wang,Zhaofeng Luo,Minchen Li,Taku Komura,Kemeng Huang*

Main category: cs.GR

TL;DR: This paper presents a GPU-oriented adaptive coarsening method for implicit time integration that dynamically reduces degrees of freedom within Newton solves without explicit topological modifications, achieving up to 3x speedup over state-of-the-art GPU IPC solvers while maintaining accuracy.


<details>
  <summary>Details</summary>
Motivation: Implicit time integration for stiff materials and large deformations is performance-limited by repeatedly solving large linear systems. Conventional explicit remeshing has drawbacks (connectivity changes, parallel implementation complications, memory locality issues, potential geometry intersections). Adaptive subspace approaches avoid topological changes but suffer from irregular data access patterns and dense matrices that limit GPU efficiency.

Method: The authors propose "algebraic adaptive in-solve coarsening" that: (1) Expresses adaptivity as a selective edge-collapse process governed by per-edge tags; (2) Uses warp-level hash mapping to aggregate collapsible edges in parallel, grouping fine vertices into coarse super-nodes; (3) Preserves local detail via protected edges; (4) Assembles coarse mesh linear system algebraically by mapping and reducing fine-scale gradients and Hessians via GPU reduction kernels; (5) Solves with preconditioned conjugate gradient (PCG) method; (6) Prolongates solution back to fine mesh; (7) Integrates with IPC's barrier energy and exploits GPU parallelism end-to-end.

Result: The approach achieves up to 3x speedup over state-of-the-art GPU IPC solver across challenging scenarios while producing visually indistinguishable results.

Conclusion: The method provides a practical solution for accelerating implicit time integration simulations on GPUs by dynamically reducing degrees of freedom during Newton solves without explicit topological modifications, maintaining accuracy while significantly improving performance.

Abstract: Implicit time integration is key to robustly simulating stiff materials and large deformations, but its performance is often dominated by repeatedly solving large linear systems. Adaptive coarsening can reduce this cost by concentrating degrees of freedom (DoF) to where it is most needed, yet conventional explicit remeshing changes connectivity (and often vertex ordering), complicating parallel implementations, harming memory locality, and sometimes being disallowed when it may introduce local geometry intersections. Adaptive subspace approaches avoid topological changes, but basis construction and updates incur irregular data access patterns and typically produce dense system matrices, limiting GPU efficiency and keeping many practical systems CPU-centric. We present algebraic adaptive in-solve coarsening, a GPU-oriented method that dynamically reduces DoF within the Newton solve of implicit time integration without explicit topological modification. Starting from a fine mesh, we express adaptivity as a selective edge-collapse process governed by per-edge tags. Collapsible edges are aggregated in parallel using a warp-level hash mapping scheme that groups fine vertices into coarse super-nodes, while protected edges preserve local detail. This defines an implicit coarse mesh whose linear system is assembled algebraically by mapping and reducing fine-scale gradients and Hessians via efficient GPU reduction kernels. We solve the resulting coarse system with a preconditioned conjugate gradient (PCG) method and then prolongate the solution back to the fine mesh. Our approach integrates seamlessly with IPC's barrier energy and exploits GPU parallelism end-to-end. Across a range of challenging scenarios, we achieve up to 3x speedup over a state-of-the-art GPU IPC solver while producing visually indistinguishable results.

### [33] [A Bayesian Approach for Task-Specific Next-Best-View Selection with Uncertain Geometry](https://arxiv.org/abs/2605.05095)
*Jingsen Zhu,Silvia Sellán,Alexander Terenin*

Main category: cs.GR

TL;DR: A Bayesian decision-theoretic framework for task-specific active next-best-view selection in 3D reconstruction, which reduces uncertainty only in task-relevant regions rather than uniformly across space.


<details>
  <summary>Details</summary>
Motivation: Existing next-best-view selection methods reduce uncertainty uniformly across space, which is inefficient for task-specific applications. There's a need for view selection strategies that focus computational resources on uncertainty reduction in regions that matter for the downstream task.

Method: The framework uses (a) a prior distribution over implicit surfaces, (b) stochastic surface reconstruction to compute the posterior distribution, and (c) Bayesian decision theory to select the next optimal view based on the posterior. This enables task-specific uncertainty reduction by evaluating views through the lens of the intended downstream application.

Result: The method outperforms commonly used baselines and general uncertainty-reduction techniques across three tasks (semantic classification, segmentation, and PDE-guided physics simulation), achieving superior task performance with significantly fewer views.

Conclusion: Task-specific active view selection through Bayesian decision theory provides a principled approach to 3D reconstruction that optimizes computational resources by focusing on task-relevant uncertainty reduction, demonstrating practical advantages over uniform uncertainty reduction strategies.

Abstract: We develop a framework for task-specific active next-best-view selection in 3D reconstruction from point clouds, by casting the problem in the language of Bayesian decision theory. Our framework works by (a) placing a prior distribution over the space of implicit surfaces, (b) using recently-developed stochastic surface reconstruction methods to calculate the resulting posterior distribution, then (c) using the posterior distribution to carefully reason about which view to scan next. This enables us to perform camera selection in a manner that is directly optimized for the intended use of the reconstructed data - meaning, we reduce uncertainty only in those regions that make a difference in the task at hand, as opposed to prior approaches that reduce it uniformly across space. We evaluate our method across three distinct downstream tasks: semantic classification, segmentation, and PDE-guided physics simulation. Experimental results demonstrate that our framework achieves superior task performance with fewer views compared to commonly used baselines and prior general uncertainty-reduction techniques.
