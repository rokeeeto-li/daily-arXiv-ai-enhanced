### [1] [Underwater C3-JEPA: An Object-Centric Cross-View World Model for ROV Salvage](https://arxiv.org/abs/2609.30214)
*Yuncong Yang,Jinlong Li,Yulong Xue,Feng Wu,Chunwen Zhang,Lei Qiao,Xuyang Wang*

Main category: cs.RO

TL;DR: A cross-view, control-conditioned, context-extended JEPA (Joint Embedding Predictive Architecture) for underwater ROV salvage that predicts future states from multi-view RGB observations without contact sensors.


<details>
  <summary>Details</summary>
Motivation: Need for object-centric predictive world models in underwater salvage operations where contact sensors are unavailable and hydrodynamic lag complicates planning.

Method: C³-JEPA encodes multi-camera observations into task-object and context tokens, fuses cross-camera evidence through held-out-view attention, directly predicts future states conditioned on control, uses weak binding for low-cost object-gripper anchoring, and SIGReg for geometric representation sharpening.

Result: The learned representation transfers substantially more task-relevant information than a reconstruction-free latent baseline while keeping the predictor lightweight, supports MPC candidate evaluation and imagined-rollout behavior-agent training, and successfully recovers withheld camera object states while staying ahead of persistence.

Conclusion: The architecture generalizes to real underwater video validation, demonstrating transferability beyond simulation and effectiveness for near-field heavy-load underwater ROV salvage tasks.

Abstract: We present Underwater C$^{3}$-JEPA (cross-view, control-conditioned, context-extended), an object-centric multi-view predictive world model for near-field heavy-load underwater ROV salvage. Without contact sensors, it predicts in latent space how the task-object state evolves through contact interaction and under the hydrodynamic lag of the vehicle, from synchronized multi-view RGB observations and vehicle control signals. C$^{3}$-JEPA encodes multi-camera observations into task-object and context tokens, fuses cross-camera evidence through held-out-view attention, and directly predicts future states conditioned on control. Weak binding anchors the target and gripper at low annotation cost, while SIGReg sharpens the geometric representation. Experiments show that the learned representation transfers substantially more task-relevant information to downstream probes than a reconstruction-free latent baseline, while keeping the predictor lightweight. The resulting predictive interface supports model-predictive-control (MPC) candidate evaluation and imagined-rollout behavior-agent training. Validation on real underwater video shows the same architecture recovering a withheld camera's object state and staying ahead of persistence, so the recipe transfers beyond simulation.

### [2] [Coding Agents for Generalized Task and Motion Planning Problems](https://arxiv.org/abs/2609.30233)
*Matteo Merler,Bowen Li,Josh Roy,Yichao Liang,Qianwei Wang,Yixuan Huang,Tom Silver*

Main category: cs.RO

TL;DR: Coding agents can effectively automate generalized Task and Motion Planning (TAMP) by synthesizing programs that generalize across instances, outperforming hand-engineered planners and other baselines.


<details>
  <summary>Details</summary>
Motivation: TAMP problems are difficult due to tight coupling between discrete decisions and geometric/kinematic/dynamic constraints. Existing generalized TAMP methods require substantial TAMP-specific engineering. The researchers investigate whether coding agents can automate this process.

Method: Evaluated Claude Code (Opus 5) and Codex (GPT-5.6 Sol and GPT-6 Astra) on 28 simulated environments from KinDER and PDDLStream. Agents have access to task descriptions and simulators with a fixed synthesis budget. Programs are frozen and evaluated on unseen instances. Tested 980 generated programs on 100 held-out instances each (98,000 episodes total).

Result: All three agent configurations outperform hand-engineered planners, one-shot generation, and LLM-based generalized planning baseline. Mean success rates: 56%-95% vs 47% for planners. Agents maintain higher success than planners as object counts grow, using an order of magnitude less computation per instance. Agents use interaction to calibrate physical models, test edge cases, and refine strategies.

Conclusion: Coding agents are a strong baseline for generalized TAMP. They can effectively synthesize programs that generalize across instances with superior performance to traditional approaches.

Abstract: Task and motion planning (TAMP) problems remain difficult even with full observability and object-centric states because discrete decisions are tightly coupled to geometric, kinematic, and dynamic constraints. Generalized TAMP addresses this difficulty by exploiting regularities across problem instances to reduce planning effort on new instances. However, existing methods require substantial TAMP-specific engineering. We investigate whether coding agents can automate this process by synthesizing programs that generalize across instances. Given a task description and simulator access, each agent chooses how to interact with the environment while developing a program within a fixed synthesis budget. The program is then frozen and evaluated on unseen instances. We evaluate Claude Code (Opus 5) and Codex (GPT-5.6 Sol and GPT-6 Astra) on 28 simulated environments from KinDER and PDDLStream, with object counts beyond those evaluated in the original benchmark. Across all program synthesis methods, we evaluate 980 generated programs on 100 held-out instances each, 98,000 evaluation episodes in total. Overall, we find that coding agents are surprisingly effective at generalized TAMP: all three agent configurations outperform hand-engineered planners, one-shot generation, and an LLM-based generalized planning baseline in mean success (56% to 95% versus 47% for the planners, on the 16 environments where a planner is available). As object counts grow, the agents' programs maintain higher success than the planner, using an order of magnitude less computation per instance on average. Logs show agents using interaction to calibrate physical models, test edge cases, and refine strategies. We release all code, including the full prompts given to the agents. These findings suggest that coding agents are a strong baseline for generalized TAMP.

### [3] [Rolling-WAM: World Action Models with Rolling Imagination](https://arxiv.org/abs/2609.30247)
*Yinghua Zhou,Junjie Ye,Yiqi Zhao,Hao Dong,Celina Shiyu Wang,Ruohai Ge,Tingyi Yang,Basile Van Hoorick,Gaurav Sukhatme,Vitor Guizilini,Yue Wang*

Main category: cs.RO

TL;DR: Rolling-WAM distributes joint video-action denoising across successive replanning cycles using a sliding window with staggered noise levels, achieving 4.5x speedup over standard WAMs while maintaining competitive manipulation performance.


<details>
  <summary>Details</summary>
Motivation: Standard World Action Models (WAMs) couple action generation with future visual prediction, but completing the joint video-action denoising process at each replanning cycle incurs substantial latency, delaying action updates and limiting closed-loop responsiveness.

Method: Rolling-WAM maintains a sliding window of video-action chunks at staggered noise levels. At each step, a rolling noise schedule fully denoises the imminent action chunk for execution while partially refining farther-future chunks. As the window advances with new camera observations, retained future chunks continue their denoising process.

Result: Evaluations on LIBERO, RoboTwin, and a real-world Unitree G1 humanoid show Rolling-WAM achieves competitive manipulation performance and delivers a 4.5x steady-state replanning speedup over standard joint WAMs.

Conclusion: By removing the need to denoise the entire prediction horizon from scratch, Rolling-WAM distributes computational cost over time while carrying evolving visual-action context across chunk boundaries, enabling more responsive closed-loop robotic manipulation.

Abstract: World Action Models (WAMs) couple action generation with future visual prediction for robotic manipulation. However, completing the joint video-action denoising process at each replanning cycle incurs substantial latency, delaying action updates and limiting closed-loop responsiveness. We present Rolling-WAM, a formulation that distributes joint denoising across successive replanning cycles. Our method maintains a sliding window of video-action chunks at staggered noise levels. At each step, a rolling noise schedule fully denoises the imminent action chunk for execution, while partially refining farther-future chunks. As the window advances with new camera observations, the retained future chunks continue their denoising process. This distributes the computational cost over time while carrying an evolving visual-action context across chunk boundaries. Evaluations on LIBERO, RoboTwin, and a real-world Unitree G1 humanoid show that Rolling-WAM achieves competitive manipulation performance. By removing the need to denoise the entire prediction horizon from scratch, it delivers a 4.5x steady-state replanning speedup over standard joint WAMs.

### [4] [RAPID: Robot Agentic Programming from Demonstrations](https://arxiv.org/abs/2609.30249)
*Yuyao Liu,Jiayuan Mao,David Hsu,Leslie Pack Kaelbling,Tomás Lozano-Pérez*

Main category: cs.RO

TL;DR: RAPID is a system that automatically generates, verifies, and refines robot programs from a single visual human demonstration, enabling reusable, generalizable robot code for manipulation tasks.


<details>
  <summary>Details</summary>
Motivation: Coding agents have demonstrated success in programming, but there's a need to extend this capability to robot systems. The authors aim to leverage agentic programming approaches for robots by automating program generation, verification, and refinement from demonstrations.

Method: RAPID introduces an iterative agentic loop with three components inferred from demonstrations: (1) testable task specification, (2) action primitives for execution, and (3) interactive environment for verification. It uses an object-centric relational program representation that focuses on underlying strategy structure rather than specific motion, expressing primitives as trajectory-optimization programs and composing them via relational constraints.

Result: Evaluated on 8 contact-rich nonprehensile manipulation tasks and LIBERO-Pro prehensile tasks. Successfully deployed on a real Franka arm. Demonstrated strong performance with generalization across object pose, shape, material, and environment variations.

Conclusion: RAPID successfully transforms visual human demonstrations into reusable, executable robot programs that generalize across diverse manipulation scenarios, effectively bridging the gap between human demonstrations and deployable robot code.

Abstract: Coding agents have demonstrated enormous success in solving complex programming problems. To leverage their potential for robot systems, this work introduces Robot Agentic Programming from Demonstrations (RAPID), which automatically generates, verifies, and refines robot programs, given a single visual human demonstration. The iterative agentic loop of code refinement requires several key ingredients: (i) a testable task specification, (ii) action primitives for robot execution, and (iii) an interactive environment for program execution and verification. RAPID infers all three from the demonstration automatically. To make the resulting program reusable beyond the demonstration setting, RAPID uses an object-centric relational program representation that focuses on the underlying structure of the demonstrated strategy rather than the specific motion per se: it expresses the action primitives as trajectory-optimization programs that realize object-level motion effects, while composing them through relational constraints that capture scene-specific geometry at run time. We evaluated RAPID in simulation on eight challenging contact-rich nonprehensile manipulation tasks as well as general prehensile manipulation tasks in the LIBERO-Pro benchmark. We also successfully deployed it on a real Franka arm and evaluated on all eight nonprehensile tasks. In all experiments, RAPID demonstrated strong performance, with generalization over object pose, shape, material, and environment. Website: https://yuyaoliu.me/projects/rapid.

</details>
